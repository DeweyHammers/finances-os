Finances OS

Set up sync

Keep this PC and your other devices in step through a free cloud database that you own. Ten minutes, two values to copy, no account with us.

How it works

Finances OS is local by default: everything lives in one database file on your PC. Sync is optional. When you turn it on, your data moves into a small cloud database in your own free Turso account, and the app keeps a copy of it on the PC. Every change you make is saved to the cloud as you make it; when the PC is offline you can still look at everything, and changes wait until the cloud is back.

There is one source of truth, so nothing ever needs merging. Nobody but you holds your data, and you can leave at any time: Export gives you a plain SQLite file, and Forget this device turns the PC back into a local-only install with the data it had.

01

Create a free Turso database

turso.tech → Sign up → Create database

  1. Go to turso.tech and sign up (GitHub or e-mail). The free plan is plenty: a budget database is a few hundred kilobytes.
  2. Create a database (any name, e.g. finances; pick the region closest to you).

Why Turso: it is hosted SQLite — the very same database engine the app uses locally — with a free tier and no server for anyone to run. The app talks to it directly; nothing passes through us.
02

Copy the two values

Turso → your database → Connect

Open the database and look for its connection details. You need:

ValueLooks likeWhere
Database URLlibsql://finances-yourname.turso.ioShown on the database page (“URL” or “Connect”).
TokenA long string starting with eyJ…“Create token” / “Generate token” on the same page. Choose read & write, no expiry (or a long one).
Screenshot: TODO — the database page with the URL and the “Create token” button highlighted.
Keep the token private. It is the key to your data: anyone with the URL and the token can read it. The app stores it encrypted on the PC (Windows DPAPI, tied to your Windows account) and never puts it inside the database or an export.
03

Paste them into Settings

Finances OS → Settings → Phone & sync → Connect

  1. In the app open Settings (bottom of the sidebar) → Phone & sync.
  2. Paste the URL into Database URL and the token into Token, then click Connect.
  3. The app uploads this PC's data into the cloud database (a few seconds), switches to it and reloads. A green Synced dot appears above Settings in the sidebar.
Screenshot: TODO — Settings → Phone & sync with the fields filled, and the sidebar showing “Synced · Last synced just now”.

If the cloud database already holds data — because you connected another PC first — the app asks which side should win: use the cloud data on this PC (the usual choice for a second device) or replace the cloud with this PC's data. Nothing is overwritten silently, and the previous local file stays on disk as a backup either way.

Reading the status

Sidebar, above Settings

DotMeaning
🟢 SyncedEverything is saved to the cloud; “last synced” is when the app last pulled other devices' changes (every minute, after every change you make, and when you click the dot).
🟡 Syncing…Pulling right now.
🔴 OfflineThe cloud can't be reached. You can look at everything; saving is refused with a clear message until it is back. Click the dot to check again.
🟡 PausedA sandbox is active. Keep or Discard it and sync resumes (Keep pushes the kept data to the cloud).
🔴 Update neededThe cloud database was written by a newer version of Finances OS on another device. Update the app on this device; until then nothing is changed or synced here.

05

Export, import, and leaving

Settings → Phone & sync

  • Export downloads a plain SQLite file of all your data, synced or not. Keep one somewhere safe now and then; it opens in any SQLite tool.
  • Import… replaces your data with an exported file (or one of the app's .bak backups). With sync on it goes to the cloud, so every device gets it. A backup of the current data is saved first.
  • Forget this device stops syncing on this PC and removes the token from it. The data stays on the PC as a normal local database; the cloud database and your other devices are untouched. Delete the Turso database from its dashboard if you want it gone entirely.
Your data, your way out: Turso's free tier is theirs to change; the export is yours to keep. The app will always be able to run local-only from an export.
